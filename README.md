## 🧠 My Problem-Solving Approach

For every problem, I try to focus on five steps:

### 1. Understand
Break the problem down and identify the constraints.

### 2. Identify the Pattern
Determine which DSA concept or problem-solving pattern applies.

### 3. Implement
Write a clean, readable, and maintainable solution.

### 4. Optimize
Analyze time and space complexity and improve the solution where possible.

### 5. Learn
Understand **why** the solution works instead of simply memorizing it.
