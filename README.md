## 🧠 My Approach to Problems

For every problem, I try to focus on:

### 1. Understand

Break the problem down and identify the constraints.

### 2. Approach

Find the appropriate DSA pattern or algorithm.

### 3. Implement

Write a clean and readable solution.

### 4. Optimize

Analyze and improve time and space complexity where possible.

### 5. Learn

Understand why the solution works instead of simply memorizing it.
